# Merge the application's text into one `ui.php` file

## Context

The application's own text is split across `lang/{en,fr}/home.php` and `lang/{en,fr}/locale.php`, and language names are hard-coded in `App\Enums\Locale::label()`. The user wants:

- one `lang/{en,fr}/ui.php` file per language, with a `common` section for keys used on every page and one section per page (`home`), each page section having a `title` and a `description` for the `<head>`;
- language names in the translation files, shown in their own language plus, for the other languages, in the current language: "Français (French)" and "English" when English is selected; "Français" and "English (Anglais)" when French is selected.

The files generated by `laravel-lang/lang` (`auth.php`, `pagination.php`, `passwords.php`, `validation.php`, `en.json`, `fr.json`) are not changed.

## Steps

1. **`lang/en/ui.php` and `lang/fr/ui.php`** (replacing `home.php` and `locale.php`, which are deleted):

   ```php
   return [
       'common' => [
           'locale_switcher' => 'Change language',   // fr: 'Changer de langue'
           'locales' => [
               'en' => 'English',                       // fr: 'Anglais'
               'fr' => 'French',                        // fr: 'Français'
           ],
       ],
       'home' => [
           'title' => 'Home',                           // fr: 'Accueil'
           'description' => 'Media player built with Laravel, Livewire and Flux.', // fr equivalent
           'introduction' => ..., 'show_message' => ..., 'hide_message' => ..., 'message' => ...,
       ],
   ];
   ```

   `locales.<code>` holds each language's name in the file's language, so the name of a language in itself is `__('ui.common.locales.fr', locale: 'fr')` ("Français") and in the current language is `__('ui.common.locales.fr')`.

2. **Enum** `app/Enums/Locale.php`: remove `label()`. The enum stays as the list of supported locales (used by the middleware, the switcher and the parity test).

3. **Switcher** `resources/views/components/⚡locale-switcher.blade.php`: add a `localeName(Locale $locale): string` method returning the name in its own language, followed by ` (name in the current language)` when it is not the current locale. Use it for the menu items. The button shows the current language's name (which has no parenthesis). Its `aria-label` uses `ui.common.locale_switcher`.

4. **Home page** `resources/views/pages/⚡home.blade.php`: use `ui.home.*` keys; `render()` returns `$this->view()->title(__('ui.home.title'))->layoutData(['description' => __('ui.home.description')])` (Livewire's `layoutData` macro).

5. **Layout** `resources/views/layouts/app.blade.php`: add `@isset($description) <meta name="description" content="{{ $description }}"> @endisset` after `<title>`.

6. **Tests**:
   - `HomePageTest`: also assert the description meta tag in both languages.
   - `LocaleSwitcherTest`: with English, the menu shows "English" and "Français (French)"; with French, "Français" and "English (Anglais)".
   - `TranslationTest` keeps working unchanged (it compares keys of every PHP file, including nested `ui` keys).

7. `vendor/bin/pint --dirty --format agent`.

No commit unless requested.
